# NeverHeardOfVPNs Ratu

**Статус:** версия 1.1.0 опубликована в [ios.ratu.sh](https://ios.ratu.sh/); обход обычного Ozon не подтверждён. Подмена внешнего IP и новая страница настроек не реализованы. См. VALIDATION.md.

Адаптация [NeverHeardOfVPNs](https://github.com/thatmarcel/never-heard-of-vpns) автора thatmarcel. Изменения ratu.sh: 2026-10-18, версия 1.1.0. Лицензия AGPL-3.0; включённая библиотека fishhook — BSD-3-Clause, её уведомления сохранены.

Твик скрывает распространённые **локальные признаки VPN внутри сторонних приложений**. Профиль VPN, маршрут, DNS и само соединение он не переключает. Сетевые библиотеки Apple продолжают получать реальные данные. Приложение должно пользоваться тем же маршрутом, который был выбран системой до скрытия.

## Совместимость

Пакет `com.thatmarcel.tweaks.neverheardofvpns`, `iphoneos-arm64`, содержит arm64 и современную arm64e. Сборка выполняется на macOS/Xcode через Theos rootless. Метаданные допускают iOS 17.0–26.0.1 при наличии совместимого jailbreak и механизма внедрения. Это не утверждение о наличии jailbreak для каждой версии iOS и не подтверждение испытаний на каждой из них. Физическое устройство для проверки: iPhone15,3, iOS 17.0 21A329, Dopamine 3.0.10, ElleKit 1.2. Подробные результаты — в `VALIDATION.md`.

## Что скрывается

- Туннельные имена `utun`, `ipsec`, `ppp`, `tun`, `tap` с произвольным числовым суффиксом; Wi-Fi, cellular, loopback и другие обычные интерфейсы сохраняются.
- `CFNetworkCopySystemProxySettings`: удаляются только туннельные ключи из `__SCOPED__`. Исходные прокси, PAC и исключения сохраняются; их значения не записываются в журнал.
- `getifaddrs` / `freeifaddrs`, `if_nameindex` / `if_freenameindex`: фильтрация с сохранением контракта выделения и освобождения памяти. При нехватке памяти возвращается исходный список.
- `NEVPNConnection.status`: известные состояния подключения заменяются на disconnected только для запросов кода приложения. Ошибки и неизвестные будущие значения сохраняются.
- `nw_path_enumerate_interfaces`, `nw_path_uses_interface_type` и доступный `SCNetworkConnectionGetStatus`: переназначение импортов исполняемого файла приложения и встроенных библиотек. Возможность этого зависит от таблиц импортов и защиты памяти конкретного процесса. Счётчики `NHOVPNBindingStats` позволяют проверить фактическое переназначение. Если запись запрещена, этот путь остаётся исходным.

Для основных API используется совместимый механизм ElleKit/Substrate. Для Network.framework инструкции общих системных функций не переписываются: обработка ограничена импортами приложения. Внутренние вызовы библиотек Apple проходят без фильтрации. Проверка использует путь исполняемого файла и библиотек приложения; индекс 0 в списке dyld не считается надёжным указателем на приложение в Dopamine.

Твик исключает системные приложения Apple, расширения, демоны и контейнеры с собственным NetworkExtension-провайдером, чтобы не мешать VPN-клиентам поддерживать туннель. Если другой VPN-клиент не содержит такого расширения, отключите для него этот твик в Choicy.

## Установка и Choicy

Обновите источник [ios.ratu.sh](https://ios.ratu.sh/) в Sileo и установите **NeverHeardOfVPNs Ratu 1.1.0**. Полностью закройте и откройте целевое приложение. Отдельной страницы настроек нет. Ограничения Ozon и непроверенные версии iOS перечислены ниже и в VALIDATION.md.

В приложении должно быть разрешено внедрение твиков. Если в Choicy стоит «Disable Tweak Injection», твик работать не сможет. Для приложений с защитой от jailbreak используйте индивидуальный список разрешений, включив только `NeverHeardOfVPNs`; остальные твики разрешать не требуется. Не меняйте настройки самого VPN и маршрутизации ради скрытия.

## Ограничения

Гарантировать невидимость для всех приложений невозможно. Внешний IP, ASN, геолокация и серверные базы VPN не меняются. Прямые route/ioctl/sysctl-запросы, адреса сокетов, приватные API, неподдерживаемые импорты и обход перехваченных функций могут выдавать туннель. Проверки, целиком выполняемые внутри системных фреймворков, могут видеть реальные данные: это сохраняет работоспособность сетевого стека. Приложения с отключённым внедрением не покрываются.

Отсутствие туннеля в ответе API не доказывает, что конкретный сервер разрешит вход. Ozon и Ozon Селект проверяются отдельно от общих тестов. Твик не отключает проверки jailbreak и не меняет ответы серверов.

## Сборка и проверки

```sh
export THEOS="$HOME/theos"
make clean package FINALPACKAGE=1
```

Полный исходный код и CI: [chelaxian/never-heard-of-vpns, ветка ratu-rootless](https://github.com/chelaxian/never-heard-of-vpns/tree/ratu-rootless).

`tests/sanitizer.mm` проверяет сохранение настроек прокси, границы имён, туннели в начале/середине/конце списка, пустой результат, ошибки, парное освобождение, значения статусов и 8000 конкурентных циклов под AddressSanitizer/UndefinedBehaviorSanitizer. CI проверяет DEB и arm64e PTRAUTH subtype `0x80000002`.

`tests/probe.mm` — отдельный диагностический инструмент, в DEB не входит. Не считайте его запуск эквивалентом App Store-процесса: на этом Dopamine самостоятельная ручная загрузка в CLI сталкивалась с защитой памяти/сигналом SIGBUS. Итоговая проверка выполняется в реальных целевых приложениях. Сетевой тест хранит только SHA256 внешнего IP, без публикации самого адреса.
